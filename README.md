Project Summary:
IoT Safeguard – Industry Protection System Using IoT & Cloud Technology
This project is designed to protect industries from hazards like gas leaks, fires, equipment failures due to high temperatures, and light failures. 
It uses an Arduino Uno microcontroller connected to gas, fire, light, and temperature sensors.
These sensors detect potential dangers and send data to a cloud platform (IoTGecko) via Wi-Fi. 
When a threat is detected, the system takes automatic preventive actions, such as activating exhaust fans, triggering alarms, providing light backup, and displaying alerts on the cloud.
This ensures real-time monitoring, remote access to data, and enhanced industrial safety.
________________________________________
Project Data Flow:
1.	Sensors Collect Data – Gas, fire, temperature, and light sensors detect environmental conditions.
2.	Arduino Processes Data – Reads sensor values and prepares them for transmission.
3.	Wi-Fi Module Sends Data – Transmits data to IoTGecko cloud platform.
4.	Cloud Platform Displays Data – The system monitors and logs sensor readings for remote access.
5.	Automated Preventive Actions – If a hazard is detected, the system triggers alarms, turns on exhaust fans, provides light backup, and sends alerts.
________________________________________
Challenges in Development:
1.	Hardware Integration Issues – Ensuring smooth communication between Arduino and multiple sensors.
2.	Cloud Connectivity & Latency – Delays in data transmission due to network issues.
3.	Power Management – Ensuring system functionality even during power failures.
4.	Sensor Calibration & Accuracy – Maintaining precise readings from sensors to avoid false alarms.
